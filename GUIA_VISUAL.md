## 💡 Tips & Trucos

### 🔍 Búsqueda Rápida
```
1. Ve a Noticias
2. Escribe en 🔍 Buscar
3. Los resultados se filtran en tiempo real
4. No necesitas presionar Enter
```

### ⚡ Crear Favorito Rápido
```
1. Desde cualquier lista de noticias
2. Busca la noticia
3. Click en ❤️
4. ¡Listo! Ya está en favoritos
```

### 📋 Copiar URL de Noticia
```
1. Abre la noticia
2. Copia la URL de la barra
3. Comparte con otros
4. Ellos verán exactamente la misma noticia
```

### 🎨 Cambiar Tema Oscuro/Claro
```
- Abre DevTools (F12)
- Elementos → html → Estilos
- Cambia --azul-oscuro por colores claros
- Experimenta con la paleta de colores
```

## ❌ Errores Comunes & Soluciones

| Error | Causa | Solución |
|-------|-------|----------|
| Noticias no aparecen | news.json corrupto | Verifica el archivo JSON |
| Login no funciona | Credenciales mal | admin / admin |
| Imágenes no cargan | URL inválida | Verifica la URL HTTPS |
| Favoritos desaparecen | localStorage limpiado | No uses modo incógnito |
| Admin no accesible | No estás logueado | Haz login primero |

## 🎓 Flujo de Aprendizaje Recomendado

```
PRINCIPIANTE (Lector):
1. Lee la página de Inicio
2. Explora Noticias (5 min)
3. Agrega 2-3 a Favoritos
4. Lee una noticia completa
5. Intenta la búsqueda
→ Tiempo: 15 minutos

INTERMEDIO (Admin en pruebas):
1. Lee el flujo de Lector
2. Haz login (admin/admin)
3. Ve el Panel Admin
4. Crea tu primera noticia
5. Edita la noticia creada
6. Elimina la noticia
→ Tiempo: 30 minutos

AVANZADO (Desarrollador):
1. Lee README.md completo
2. Explora LOGIN_IMPLEMENTATION.md
3. Estudia LOGIN_FLOW.md
4. Abre el código en editor
5. Modifica estilos/funcionalidad
6. Agrega nuevas características
→ Tiempo: variable
```
